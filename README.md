# INT331 Collaborative Software Development Lab

## Course
INT331: Fundamentals of DevOps

## Practical
Collaborative Software Development using GitHub Issues, Forks, and Pull Requests.

## Purpose
This repository is the faculty/upstream repository for the INT331 GitHub collaboration practical.

Students will practice:

- GitHub Issues
- Forking repositories
- Cloning repositories
- Creating branches
- Making commits
- Pushing changes
- Creating Pull Requests
- Reviewing and merging Pull Requests

## Instructions for Students

1. Open this faculty repository.
2. Create the assigned GitHub Issue.
3. Fork this repository into your personal GitHub account.
4. Clone your fork to your computer.
5. Create a new branch.
6. Complete the assigned task.
7. Commit and push your changes.
8. Create a Pull Request to this faculty repository.
